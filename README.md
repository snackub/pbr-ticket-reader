# 屋島P&BR 利用券読取システム

GitHub Pages向けのPOCです。1枚の利用券を1台の車両として扱い、実験日ごとの乗車（IN）・帰着（OUT）を記録する画面を用意しています。

## 現在の状態

HTML・CSSによる画面プレビューです。カメラ読取、人数テンキー、登録、保存、集計処理、出力、削除は未実装で、対応するボタンは無効になっています。

IN／OUTの選択、実験日の表示変更、人数入力パネルと全件削除パネルの開閉を確認できます。人数欄へ直接入力しても記録や保存はされません。

日付の初期表示 `2026-11-21` は画面確認用の例です。実際の利用記録は含めていません。未OUTは未帰着の車両数であり、実際の駐車台数とは限りません。

## 画面を確認する

`index.html` をブラウザで開いてください。CSSは同じフォルダの `styles.css` を読み込みます。画面確認にサーバーや依存パッケージのインストールは必要ありません。

## ファイル

- `index.html`: スマートフォン・PC向けの画面構造
- `styles.css`: レスポンシブレイアウトと表示スタイル
- `.gitignore`: ローカルのプレビュー資材・出力先などの除外設定

外部フォント・外部CDN・アクセス解析は使用していません。GitHub Pagesの公開設定は、別工程で行います。

## 今後の実装

- 実験日・5桁券番号の検証とIN／OUTの重複防止
- 人数の確定入力、読取時刻の記録、日別の集計・履歴表示
- localStorage保存と保存失敗時のエラー表示
- 選択日のCSV／JSON出力と確認付きの削除
- html5-qrcodeの同梱、Code128／QR読取、使用端末での確認

利用記録・出力ファイル・社内資料・秘密情報はリポジトリに追加せず、CSV／JSONの出力先は作業フォルダの外にしてください。
